# 步骤 1 / 2 / 5 工程级内容模板与防错脚本规范（v5.1）

> 本规范确保教师只发 1–2 句大白话，也能产出结构严谨、数字 100% 自洽、排版美观可打印的教材清单、教案、红笔双卷、阅卷诊断报告与错题急救卡，彻底杜绝“表里写 1 人、文字写 2 人”或“学生卷漏出答案/分值不等于 100”等失误。

---

## 一、步骤 1：《教材核验清单.md》固定输出结构（兼容电子版与扫描版 PDF）

调用 `k12_studio.py scan-pdf` 与 `extract-pdf` 提取真教材章节（若检测到纯图片扫描页，自动输出高清页面图与拼图总览 `<work_dir>/scanned_pages/pages_contact_sheet.png` 供视觉逐页核对），按以下 6 个固定小节落盘至 `01-教材/教材核验清单.md`：

1. **版本与页码元数据表**：书名、出版社、审定年份/《后记》印次日期、原 PDF 总页数、载体类型（电子文字版 / 扫描图片版）、本章教材页码 vs PDF 物理页码映射、节选 PDF 文件名与总页数。
2. **整章结构与书签目录表**：按节/小标题列出教材页码、核心知识点、例题/课文篇目编号与课时权重。
3. **教材原例题/课文关键点与「做一做/思考探究」精确台账**：逐条记录页码、原始数据或原句、单位、图注细节，以及**教材故意留空待学生填写的空位**（标记 `[教材留白·课件严禁提前印死答案]`）。
4. **课后练习题原始数据清单**：逐套列出题号、页码、带 `*` 选做题标记与阅读拓展栏（明确标记 `[仅阅读拓展·不入必考]`）。
5. **关键插图与实验/语境细节核验**：记录实验器皿规格、光路/电路连接、操作步骤、精度要求（如小学数学统一 `π ≈ 3.14`）及生活实际取近似值规则。
6. **本学段知识边界与禁超纲红线（≥ 6 条）**：明确列出本学段绝对禁止引入的公式、解法、超纲词汇或史料误读红线。

## 二、步骤 2：整章规划 + 分课时教案固定结构（控制打印页数）

1. **`02-教案/<单元名>_整章课时规划.docx`（严格 2 页 A4 内）**：
   - 单元知识脉络图（表格或结构树清晰呈现前后承接关系）
   - 「单元课时分配总览表」：`| 课时 | 课题 | 教材页码 | 核心学习目标 | 关键实验/活动 | 选做与分层作业 |`（含 1 节机动检测讲评课）
2. **`02-教案/<课题>_教案.docx`（单课时严格 3–4 页 A4 内，调用 `k12_studio.py docx ... --compact`）**：
   - 基本信息（学段、版本、课时、40/45 分钟）
   - 教材与学情分析（点出学生已有经验与最大认知障碍）
   - 教学目标（对应 2022 新课标核心素养）与重难点
   - 精确到分钟的课堂流程表：`| 环节与时长 | 教师核心问题与引导 | 学生实作与预设回答 | 教学意图 |`
   - 清晰板书设计（用 ` ``` ` 代码块呈现带边框左色标的独立板书框，字少意明，可照抄上黑板）
   - **「课堂高频卡壳预警与一句话救场表」（至少 5 条）**：`| 序号 | 高频卡壳点 | 课堂典型错例 | 老师脱口而出的一句话救场话术 | 顺势追问 |`
   - 附：小组合作分工单（若含实验/研讨）+ 经程序验算 100% 准确的教材随堂题参考答案。

## 三、步骤 5：单源防幻觉双卷与程序化阅卷诊断规范

### 1. 出卷必走单源 Schema 验算与双卷自动导出（`k12_studio.py verify-exam` + `assets/exam_spec.schema.json`）
- 严禁心算写卷子！先参照 `assets/exam_spec.schema.json` 在工作空间临时目录用 Python 计算并写出 `<work_dir>/exam_spec.json`（每道计算/解答题填好 `answer_lines` 答题行数、`answer`、`analysis`、`rubric`），直接调用内置命令一次性完成 100 分验算与学生/教师双卷 Markdown 同源生成：

```bash
python "{skill_dir}/k12_studio.py" verify-exam "<work_dir>/exam_spec.json" --target-total 100 --export-student-md "<work_dir>/exam_student.md" --export-teacher-md "<work_dir>/exam_teacher.md"
python "{skill_dir}/k12_studio.py" docx "<work_dir>/exam_student.md" "05-课后测改补/<课题>_学生测试卷.docx" --mode student --compact
python "{skill_dir}/k12_studio.py" docx "<work_dir>/exam_teacher.md" "05-课后测改补/<课题>_教师解析卷.docx" --mode teacher --compact
```

- `scripts/md_to_docx.py` 专项排版保障：
  - **学生卷（`--mode student`）**：自动渲染双底线 `[试卷抬头]`（班级/姓名/学号/得分）与虚线书写行 `[答题线:N]`，并硬性拦截任何残留 `【答案】`/`【解析】` 行，确保 0 答案泄露；
  - **教师卷（`--mode teacher`）**：自动将标题、`【答案】`、`【解析】`、`【评分标准】`、`【易错警示】` 与行内 `[红字:...]` 渲染为醒目的**批改朱砂红（`#C83228`）**。

### 2. 批量阅卷诊断：杜绝“表文矛盾”的单源汇总（`k12_studio.py verify-grading`）
- 批改 `05-课后测改补/课后测试/` 全部答卷时，将每份卷子的逐题得分与错因标签写入 `<work_dir>/grading_records.json`（可选附 `item_max_scores` 校验超满分异常），运行内置单源聚合命令：

```bash
python "{skill_dir}/k12_studio.py" verify-grading "<work_dir>/grading_records.json" --export-summary-md "<work_dir>/grading_base.md"
```

- 直接复用脚本输出的 `mean`、`median`、`item_summary` 与 `error_summary[tag]["ratio"]` 扩充教学改进建议并转为 Word，彻底杜绝“表格写 1 人错、正文小标题误写 2 人”的统计矛盾。
- **诚实边界**：若答卷为模拟测试样本，在报告首行注明样本属性；若为真实手写拍照卷，提示教师对潦草字迹与作图题做人工抽检复核。

### 3. 错题急救小卡与 3 级变式题（固定 2 页 A4，`--mode card` + `[分页]`）
- **第 1 页（错题急救小卡，裁剪贴错题本）**：
  - 「高频死穴 × 错误现场 × 一句话正解」3 列对照表
  - 带醒目朱砂左边框的口诀框：`> [!三步防呆口诀] ...`
  - 「交卷前 10 秒打勾自查清单」（使用 `- [ ] ` 自动渲染可打勾方框 `□`）
  - 底部留个人订正栏：`[答题线:3]`
- 中间插入独占一行的 `[分页]`，强制换至第 2 页：
- **第 2 页（3 道同类梯度变式巩固题）**：
  - ★ 基础仿练 → ★★ 情境迁移 → ★★★ 综合易错拔高（每题留 `[答题线:3]`，全部经 Python 验算），附页底参考答案与避坑提示。
